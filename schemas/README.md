# Schemas

IDML RELAX NG schemas generated by InDesign, one local folder per build.
Version folders, including their source manifests, are ignored by Git; restore
them with `./schemas/download.sh` from the repository root. Only this README,
`SHA256SUMS` and `download.sh` are tracked here.

The model in `crates/idml` is generated from the version configured in its
`Cargo.toml`; all snapshots date the schema items
(`crates/idml/schema-history.tsv`, `docs/schema-changes/`). Files are kept exactly as published or
generated. `SHA256SUMS` lists every schema file; each folder's `manifest.json`
records its source and upstream changes.

## Reproduce

```sh
./schemas/download.sh            # download the published folders and write their manifest.json
./schemas/download.sh DIR        # the same into DIR
./schemas/download.sh --verify   # check every file present against SHA256SUMS and download.sh
./scripts/generate-idml-schema/run.sh   # generate the installed InDesign's schemas (macOS)
```

The download needs Bash, `curl`, and either `sha256sum` or `shasum`. It restores
every published folder exactly (pinned commits, checked against `SHA256SUMS`)
and checks existing files without replacing them. `--verify` requires all
listed snapshots to be present. InDesign is only needed to generate a new
snapshot with the macOS launcher.

The library builds from its checked-in Rust model without schemas. Tests and
model generation require the local snapshots; see the root [README](../README.md)
for build, test and generator commands.

To add a version, add its source to `download.sh` and its files to
`SHA256SUMS`. A version generated with `scripts/generate-idml-schema` has both
forms and its own `manifest.json`; these stay local. Publish the snapshot
somewhere downloadable and record its source and hashes before making it the
configured schema version for other contributors.
